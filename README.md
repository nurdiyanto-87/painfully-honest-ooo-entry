A painfully honest out-of-office auto-reply for make.fun's "The
Painfully Honest Out-of-Office" bounty: the sender admits to
deliberately ignoring the inbox so they can actually rest, while
promising the urgent emails get answered first on return — honest
enough to sting, polite enough to survive being forwarded to a
manager.

`main.py` (pure Python standard library) writes the reply to
`/output/entry.txt` — one sentence, 176 characters, valid UTF-8.

## Run it

```sh
python3 main.py
```
